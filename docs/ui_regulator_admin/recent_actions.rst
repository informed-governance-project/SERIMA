Recent Actions
~~~~~~~~~~~~~~~~~~~~~~~

The **Recent Actions** is the sixth section on the **Administration Console** of the Regulator Admin user type. As its name implies, it displays the recent actions of the logged-in user in reverse chronological order, from most recent to oldest. Clicking a link takes you to the screen where the action occurred.
