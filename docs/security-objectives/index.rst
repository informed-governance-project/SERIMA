Security Objectives
===================

The Security Objectives module is a self-assessment tool. Operators declare how they meet the
security objectives of their regulator's framework and provide evidence of the measures in place;
regulators review and score those declarations.

- **Operators** fill in and submit a declaration.
- **Regulators** review declarations and follow the scoring.
- **Regulator Admins** configure the standards, domains, objectives and measures.
