Modules
=======

The main components of the software are as follows:

- the governance platform (settings, administration panel and core
  components). The governance platform provides access to the various modules hosted on the platform;
- the Incident Notification module (models and views related to the
  incidents notifications);
- the Security Objectives module (operator declarations against a regulator's framework, and their review);
- the Reporting module (report projects, risk-analysis import and report generation).

The Security Objectives and Reporting modules are enabled per regulator by the Platform Admin.


Incident Notification
---------------------

The Web interface is used to report and track incidents.
