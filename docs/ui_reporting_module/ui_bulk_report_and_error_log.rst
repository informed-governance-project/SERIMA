Bulk Report Generation
------------------------
  
You can select multiple operators at once when generating a report. 
In this case, the application creates a separate report for each operator. Separate PDF reports are generated: one for each selected operator.

Error log
-----------------
  
If an error occurs during report generation, an error log will also be created where you can see what the problem is. 
For example, it might happen that for the chosen year the selected operator does not have a certain type of data; therefore, a report cannot be generated.
